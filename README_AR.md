# مشروع أرتل للأندرويد

هذا المشروع يحوّل نسخة الويب المرفقة من أرتل إلى تطبيق Android يعمل محليًا دون الحاجة إلى Cloudflare أو الإنترنت.

## البناء عبر GitHub Actions
1. ارفع محتويات هذا المجلد إلى مستودع GitHub جديد باسم `Artel-Android` (مع إظهار الملفات المخفية حتى يظهر مجلد `.github`).
2. افتح تبويب **Actions** وفعّل workflows إذا طلب GitHub ذلك.
3. اختر **Build Artel APK** ثم **Run workflow**، أو ادفع commit جديدًا إلى فرع `main`.
4. بعد نجاح البناء افتح نتيجة التشغيل، ثم نزّل artifact باسم `Artel-debug-apk` وفك ضغطه لتحصل على `app-debug.apk`.

## ملاحظات مهمة
- بيانات التطبيق محفوظة محليًا داخل مساحة التطبيق على الهاتف (WebView localStorage). حذف التطبيق أو مسح بياناته قد يحذف السجلات؛ صدّر نسخة JSON دوريًا.
- زر تصدير النسخة الاحتياطية يستخدم نافذة حفظ Android، وزر الاسترجاع يفتح منتقي ملفات Android.
- هذا APK تجريبي موقّع بمفتاح debug للتجربة والتثبيت الشخصي، وليس إصدار متجر Play.
- قبل استيراد نسخة 16 أكتوبر، تأكد أن التطبيق الجديد لا يحتوي على بيانات تريد الاحتفاظ بها؛ الاستيراد الحالي يستبدل بيانات الطلاب والتسميعات الموجودة.
